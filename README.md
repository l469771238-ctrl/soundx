# لوحة الأصوات (Android)

نفس أداة `sound-pad` بنفس الواجهة، متغلّفة في تطبيق أندرويد (WebView).

## بناء الـ APK من غير ما تثبّت أي حاجة
1. ارفع كل محتويات المجلد ده على مستودع GitHub جديد (فرع `main`).
2. افتح تبويب **Actions** وشغّل **Build APK** (بيشتغل تلقائي مع أول رفع).
3. بعد ما يخلص (حوالي 5 دقايق): نزّل `SoundPad.apk` من **Releases ← latest** أو من **Artifacts** جوه تشغيلة الـ Action.
4. على الموبايل: افتح الملف، واسمح بالتثبيت من المصدر ده لو طلب.

## ملاحظات
- التصدير وحفظ الأصوات بيروحوا لمجلد **Downloads**.
- المخزون محفوظ جوه التطبيق؛ صدّره من وقت للتاني كنسخة احتياطية.
- الأيقونات والخط بيتحمّلوا من الإنترنت.
- الـ APK ده debug وموقّع بمفتاح debug، مناسب للاستخدام الشخصي.
